# PancreAI

AI-powered software for pancreatic cancer detection from CT Scan and MRI images.

## Features

- DICOM Upload
- Image Processing
- AI Prediction
- Confidence Score
- Heatmap
- PDF Report

## Technologies

- Python
- PyTorch
- FastAPI
- React
- PostgreSQL
